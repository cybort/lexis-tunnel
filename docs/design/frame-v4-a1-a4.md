# 帧词编码 v4 对比方案 A1–A4（frame.dte 开关）

4.0 默认已不是 A0。默认是方案 K（`bb-k-v4`）。下文「推荐默认 A0」是 2026-11-02 的测量结论，早于方案 K，不要当成当前默认。A1 仍不推荐。

基线 A0 = `bb-v4`（见 frame-v4-bitsback.md）。A1–A4 共用 `src/lib/lexis/v2/bbx.ts`，都建在 bb-v4 的公开模型精确区间划分上，只差四个开关。各分支只改默认 dte 和协议名；所有 dte 在每个分支里都能用 `frame.dte` 选。两端必须相同，线上不协商，未知值拒绝启动。

| 编号 | frame.dte | 协议名 | 开关 | 做法 |
|---|---|---|---|---|
| A0 | `bb-v4` | lexis-hctr2-bb-v4 | — | 满射 bits-back，CSPRNG 尾 |
| A1 | `bb-c8-v4` | lexis-hctr2-bb-c8-v4 | c8 | 方案 2：8 位轨迹闭合。parse(W) = X(W) ⊕ G(d(W))，d = r8(W) ⊕ H8(W)。改动尾词会以 255/256 的概率改变密文。发送端取 d0 均匀，重采 CSPRNG 尾直到 d(W) = d0（期望 256 次）。 |
| A2 | `bb-ou-v4` | lexis-hctr2-bb-ou-v4 | tilt | 方案 1：OU 均值回归。每个词前按信息偏差 dev = I_t − μt 在 5 张公开表 p^β（β = .92 .96 1 1.04 1.08，T = 3 bit）里选一张。长度余量改为 Z·min(σ√m, S∞) + K0。 |
| A3 | `bb-ouc8-v4` | lexis-hctr2-bb-ouc8-v4 | tilt + c8 | 方案 1 + 方案 2，ring 关 |
| A3r | `bb-ouc8r-v4` | （同 A3 分支，子项） | tilt + c8 + ring | 另外对 m ≤ 64 词的小帧收紧余量，失败的在 CSPRNG 尾上重采 |
| A4 | `dfa-v4` | lexis-hctr2-dfa-v4 | canon | 方案 3B：不用 bits-back。规范编码（尾比特 = PRG(C)），词数可变，n = ⌊(I(W) − KC)/8⌋，n 跳过时换 pad 重试。 |

结论：A2/A3/A3r 的 OU 倾斜对任何观察者可见（公开模型下能直接算出每个词用了哪张表），A4 的规范编码可被重编码一眼认出，都不能用。A1 保持不可区分并堵住尾词可塑性，但发送端慢 8–54 倍。推荐默认 A0；A1 作为可选项保留，若要作为默认需要先把发送端的 256 次期望重采降下来。
