词隙客户端 1.3.0

这是同一份通信进程。Windows、Linux、Android（Termux）都读 lexis.config.json。需要 Node.js 22。目录里还要有 lexis-frame.mjs 和 zstd.wasm。安装包不带 TLS 私钥。要听 tls 或 wss，把自己的证书和私钥放到程序旁边，命名为 lexis-tls.crt 和 lexis-tls.key。两边都没有时，如果本机有 openssl，进程会在旁边生成一把，只给这一台用，不要把那把私钥分发出去。

转发正文和控制台是同一套词表。两端用长期公钥做 ECDH，会话密钥用 Argon2id。常驻进程用自己配置里的内存、迭代和并行，不采用对端报上来的更高开销。伪造问候要先过握手口令。口令写在 link.token，两端相同，至少 8 个字符。它在 Argon2 之前校验，不是词表密钥。过期的问候和同一个时间窗里的重放都会被拒绝。

计数器、密钥流和秘密词表把明文写成散文。明文第一个字节决定是原文还是 zstd。蜜文打开时，校验对不上不报错，而落成公开词表里的另一句话。计数器接近上限，或时间窗换了，会话里会换一把密钥。心跳如果连续三个周期没有收到对端，这条会话会关掉。

外层只负责把头和协议走完，方便过 CDN：
- tcp：一行一句词表
- tls：同一句词表走在 TLS 应用数据里。正式部署请换成自己的证书，并打开校验。tlsVerify 为 false 时进程会警告
- ws / wss：一条 WebSocket 文本消息就是一句词表，路径默认 /lexis。CDN 若自己终结 TLS，源站听 ws，客户端连 wss，并填 CDN 的主机名

身份写在 identity。peers 里放要加入的节点，公钥必须对上。导出的配置带本机私钥，不要外传。没有口令校验位，换一把密钥不会提示口令错误。改名单不用重启：摘掉的节点，会话会关掉。

一条会话上可以开多路。打开命令是 `tcp 主机 端口`、`udp 主机 端口`、`relay 节点 tcp 主机 端口`，或 `expose 服务名`。中继默认关闭。想让某个节点借本机中继，把那个节点的 relay 设为 true。targets 写了就只允许那些目标，空着不限制。跳数超过 4 就拒绝。把流送回上一跳也会拒绝。某一路读得慢，只堵住这一路，不会拆掉整条会话。

NAT 后面的机器用边缘角色连出去。exposes 里写服务名、本机 host:port，以及允许访问的节点名或编号。公网闸门用 reverses 在本地听一个端口，从已经连进来的会话反向打开同名服务。也可以访问「节点名:服务名」。没有那条会话时，会说没有来自该节点的会话。断线后边缘角色会退避重连。

SOCKS 接受 CONNECT 和 UDP ASSOCIATE，UDP 可以是 IPv6。http 入站是 HTTP 代理，支持 CONNECT 和绝对地址的普通请求，认证跟 SOCKS 用同一对用户名密码。socksAuth 的用户名和密码都填了才认证，留空就不认证。

固定端口：进程监听配置里的端口。SOCKS 和 HTTP 给本机程序当代理；TCP 入站按目标转发；tunnel 入站做词表握手，然后接受上面的打开命令。
系统接管：进程仍常驻，并写出平台脚本。Linux 在有 root 时写 iptables redirect，或一条 tproxy 规则；tproxy 还不会取原始目的地址，也没有策略路由，所以并没有真正接管。Windows 的 portproxy 只绑 127.0.0.1；WinDivert 只留下说明，驱动不在包里。Android 写出 vpn-session.json 给 VpnService，Termux 本身打不开系统 VPN。没有虚拟网卡。

SOCKS、HTTP 和固定转发默认只绑 127.0.0.1。只有 link.allowLan 为 true 时才按配置里的地址监听。隧道入口可以听更宽的地址。
出口拨号前会先解析域名。回环、内网、链路本地、运营商级 NAT 和文档地址默认拒绝。egress.allow 一行一个主机、主机:端口或 IPv4 网段，用来单独放行。这道拦截不作用于你本机 SOCKS 的直连和绕行，也不作用于你自己暴露的本机服务。公网的 22、80、443 不单独封禁。握手超时、拨号超时和同时握手数在 link.handshakeMs、link.dialMs、link.maxHandshakes。

程序名：接入、绕行或拒绝。Linux 从 /proc 认进程，Windows 用当前连接的进程名，Android 上认不到进程时规则仍留在配置里。
路由：DOMAIN、DOMAIN-SUFFIX、IP-CIDR、GEOSITE、GEOIP、PROCESS-NAME、MATCH。内置 geosite/geoip 是一份小样。完整库把文本 URL 填进配置，客户端启动时拉取。域名还不会先解析再套 IP 规则。没有单独的 DNS 入站。

安装：
- Windows：在解压目录里运行 install.ps1。登录后任务 LexisAgent 会把进程拉起。证书只有你自己放进来时才会复制。
- Linux：sh install.sh。有 systemd 就装用户服务，没有就 nohup。
- Android：在 Termux 里 sh install.sh。

状态页默认是 http://127.0.0.1:17890/
控制台导出的 JSON 覆盖 lexis.config.json。名单和吊销会自己重读。两端都要把对方公钥放进 peers，并写同一个握手口令。
